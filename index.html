ABOUT THE PROJECT

Building Smarter Aircraft Operations

Smart Aircraft Operation ML is a machine learning project designed to study flight delays using real-world flight information.

The project compares three ensemble learning approaches: Bagging, Boosting and Stacking. The goal is to understand how machine learning can support smarter flight operations.
